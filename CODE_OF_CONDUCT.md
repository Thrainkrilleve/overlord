# Code of Conduct

Be respectful in issues, pull requests, and discussions. Harassment, hate speech, and personal attacks are not welcome.

Overlord can ban, kick, and timeout Discord users. Do not use this project to ask for help evading moderation, building raid tools, or targeting people.

Do not post Discord tokens, `.env` files, private transcripts, or other people's personal data. Redact logs before you share them.

Report unacceptable behavior to the repository owner through GitHub. For a security vulnerability, use [SECURITY.md](SECURITY.md) instead of a public issue.
